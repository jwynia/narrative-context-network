# Manuscripts Overview

## Classification
- **Domain**: Writing/Production
- **Stability**: Stable
- **Abstraction**: Concrete
- **Confidence**: High

## Purpose
This section manages the relationship between the context network and actual manuscript files, ensuring consistency and traceability throughout the writing and revision process.

## Key Components

### Integration Patterns
- [Source File Linking](integration/source_linking.md) - Connect context nodes to manuscript locations
- [Chapter Mapping](integration/chapter_mapping.md) - Track narrative structure across files
- [Version Control Strategy](integration/version_control.md) - Manage draft iterations

### Tracking Systems
- [Discovery Records](tracking/discoveries.md) - Capture insights during writing/revision
- [Location Indexes](tracking/location_indexes.md) - Quick reference to key narrative moments

### Format Support
- [Standard Manuscript](formats/standard_manuscript.md) - Traditional publishing format

## Usage Patterns

### During Writing
1. Create location indexes as you write key scenes
2. Log discoveries about character voice or plot connections
3. Update chapter mapping when structure changes

### During Revision
1. Use consistency logs to track changes across drafts
2. Reference location indexes to find specific moments quickly
3. Create discovery records for revision insights

### During Editing
1. Track editorial feedback in context network
2. Link specific edits to manuscript locations
3. Maintain version history for rollback capability
