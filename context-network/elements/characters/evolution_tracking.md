## Change Validation Checklist

```markdown
## Arc Consistency Check

### Setup Payoff
- [ ] Every growth moment has earlier setup
- [ ] Final state contrasts clearly with initial
- [ ] Change feels earned, not given

### Milestone Spacing  
- [ ] Growth distributed throughout story
- [ ] No sudden personality shifts
- [ ] Backsliding before breakthrough

### Relationship Impact
- [ ] Changes affect all relationships
- [ ] Others notice and react to growth
- [ ] New dynamics emerge from changes

### Voice Evolution
- [ ] Speech patterns reflect internal change
- [ ] Vocabulary/metaphors shift appropriately  
- [ ] Consistency within each phase
```
